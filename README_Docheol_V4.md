# 환조 — 첫 보스 도철 V4

Windows x64 / Unity 6000.3.23f1. `Hwanjo_Docheol_V4.exe`와 같은 폴더의 `Hwanjo_Docheol_V4_Data`, Unity DLL을 함께 유지하세요. Unity 프로젝트의 실행 씬은 `Assets/BossFight/Scenes/DocheolArenaV4.unity`입니다. 기존 V3 R1 및 VisualQa 실행 폴더는 별도로 보존했습니다.

대시는 이동 회피이며 무적을 추가하지 않습니다. 플레이어의 기존 이동·공격·점프·대시·피격 잠금을 유지합니다. 피격 후 기존 0.8초 무적과 공격·대시의 입력 제약은 그대로입니다.

## 달라진 전투

- 뿌리 중앙에 겹쳐 공격하는 동안 보스가 짧게 거리를 확보합니다. 일반 이동은 한 번 최대0.95유닛, 비공격 백대시는 최대1.65유닛·쿨다운4.8초입니다. 이동과 방향 전환 중에도 보스를 때릴 수 있습니다.
- 머리와 붙은 몸을 거두어 뿌리 중앙을 지나 반대쪽으로 펴는 방향 전환은0.78초, 뒤 안정 시간은0.14초입니다. 시작한 회전은 플레이어가 다시 넘어가도 끝냅니다. 공격 예고가 시작되면 방향·타격 범위가 고정됩니다.
- 벽에서는 같은 쪽에서 가능한 거리 조절을 먼저 합니다. 조절이 막히면 쿨다운·낙석·공격 약속 조건을 만족할 때 중앙 쪽 고정 착지 땅굴을 사용할 수 있습니다. 보스의 접촉 피해나 강제 밀기는 추가하지 않았습니다.
- 양 페이즈 기본기는 물기3, 앞발 쓸기2, 물기→앞발3→2입니다. 전진 내려찍기1 및2→1·3→2→1은 사용하지 않습니다. P2는3→2의 선택 가중치가 높고 단독기도 남습니다.
- 실제 키보드 검수에서 보인 자홍색 대시 먼지는 보스 씬의 복제된 먼지 렌더러에 기존 호환 머티리얼을 연결해 고쳤습니다. 원본 플레이어·효과 파일은 수정하지 않았습니다.

## 기본 패턴 템포와 반격

수치는 현재 조정 가능한 초기값입니다. 실제 고정 물리 스텝과 피격 정지 때문에 화면에서의 벽시계 시간은 조금 달라집니다.

| 기본기 | 예고 | 타격 | 마지막 회복 | 회피·반격 |
| --- | --- | --- | --- | --- |
| 물기3 | 0.95초 | 0.16초 | 0.30초 | 주황 범위 밖으로 이동한 뒤 짧게 공격 |
| 앞발2 단독 | 0.50초 | 0.16초 | 0.34초 | 점프 또는 대시로 실제 낮은 타격 범위를 벗어난 뒤 공격 |
| 3→2 | 물기0.95초, 연결0.08초, 앞발0.30초 | 각0.16초 | 0.34초 | 물기 후 앞발까지 회피하고 마지막 회복에 공격 |

물기는 뿌리 기준 앞쪽0.9~3.5유닛, 앞발은-0.65~4.2유닛의 낮은 범위를 사용합니다. 3→2는 처음 예고 전에 선택하며 중간 회복을 넣지 않습니다. 후속 앞발의 고정 범위는 연결 때부터 표시합니다. 중간에 공격을 욕심내면 피격 위험이 있지만 후속 공격을 입력에 반응해 새로 만들지는 않습니다. 회복을 시작하면 이동·백대시로 취소하지 않습니다.

## 땅굴과 좌우 전신 물기

땅굴은 양 페이즈 모두 잠수→이동→높은 전방 도약→고정 착지→지연 낮은 충격파입니다. 착지 위치는 첫 잠수 예고부터 고정됩니다. 착지 타격0.16초 뒤0.44초 기다리고, 높이0.42유닛 파동이0.90초 동안 양쪽으로 퍼집니다. 착지 범위를 먼저 벗어나고 파동이 다가올 때 점프하세요. 착지와 파동은 같은 공격 ID를 쓰므로 한 패키지에서 중복 피격시키지 않습니다. 피해는1이며 ‘낮은’은 높이를 뜻합니다.

땅굴 후에는1.15초 휴식 또는 미리 선택한 해당 페이즈 기본기로 이어집니다. 연계는0.24초 준비 뒤 필요한 거리·회전을 마치고 첫 기본기 예고를 최소0.90초 줍니다. 반복 도약이나 즉시 후속 타격은 없습니다.

P2 전신 물기는 뿌리를 중심으로 몸 전체가 좌우로 넘어가며 **총2회**, 처음 방향 한 번·반대 방향 한 번을 물어뜯습니다. 처음 예고1.05초, 두 타격 시작 사이 약1.41초, 각 타격0.16초, 마지막 회복1.70초입니다. 양쪽 바닥 영역은 처음부터 표시되고 공격 도중 플레이어를 따라 바뀌지 않습니다. 표시된 쪽을 벗어나 두 번째 타격까지 확인한 뒤 긴 회복에 반격하세요. 특수기 쿨다운은8.5초이며 P2에서 낙석이 없을 때 선택될 수 있습니다.

## 갑주·페이즈·낙석

보스 체력은 공유HP40입니다. 부위별 체력은 없으며 맞은 부위와 무관하게 정해진 순서로 갑주가 떨어집니다. HP30에서 첫 갑주, HP24에서 두 번째, HP20에서 세 번째를 벗기고 전환 시작 때 남은 갑주를 모두 제거합니다. 현재 공격 패키지와 약속한 회복을 끝낸 뒤 전환합니다.

전환은 갑주 탈락→짧은 그로기→포효 순서로1.70초입니다. 이 구간은 조작·양쪽 피해를 잠급니다. P2 조작 반환 뒤0.40초가 지나 첫 낙석 예고가 생성되고, 각 고정 예고는 최소0.95초입니다.

낙석은 무작위 반복 특수기가 아닙니다. **P2 진입 한 번, P2 HP10 이하 후반 한 번**만 예약합니다. 후반 조건이 공격 도중 충족돼도 공격과 마지막 회복을 끝낸 다음 숨고르기·포효 후 발생합니다. 이미 보스가 죽으면 후반 낙석을 생략하며 이벤트를 강제하려고 HP를 묶지 않습니다. 각 창은5.5초이고 남아 있는 돌은 끝까지 처리합니다. 낙석 중에는 기본기 계열만 사용하고 땅굴·전신 물기는 선택하지 않습니다.

돌 위치와 주황 예고는 고정되고 기존 시간별 안전 경로 검사를 유지합니다. 경로 검사에는 입력이 이동에 반영되는 두 물리 틱과30FPS 한 프레임의 이동 여유를 추가했습니다. 이는 안전 경로의 판단 여유이며 실제 피해 범위·피해량을 늘리지 않습니다. 공격·대시 등 이동이 잠긴 동안 새 돌 배치와 새 기본기 선택은 보류할 수 있습니다. 따라서 입력과 위치에 따라 돌 수·밀도가 달라집니다. 기존 F6 설정과 낙석 중 화면 진동 상한을 유지했습니다.

## 검증과 한계

검증 결과·정지 PNG·빌드 식별은 프로젝트 밖 `QA/V4/verification.md`와 `artifact-audit.json`, 프로젝트 `Assets/BossFight/QA/README.md`에 기록합니다. 일반 실행에는 QA 옵션을 넣을 필요가 없습니다.

자동 입력 봇의 승리는 회피·반격이 가능한 실행 사례입니다. 낙석 봇은 내부 경로 API를 읽고 일부 단위 검사는 초기 위치·패턴·페이즈 HP를 설정합니다. 실제 OS 키보드 검사는 별도 기록합니다. 모두 에이전트의 구조화된 검사이며 사람의 재미·적정 난이도·음향 취향 판정은 아닙니다. HP7 승리만으로 쉬움/적절함을 결론내리지 않습니다.

방향 전환과 전신 물기는 기존 2D SpriteRenderer/Transform 리그로 구현했습니다. 중앙을 지나며 실루엣이 얇아지는 순간이 있고 이는 입체 회전용 신규 아트가 아닙니다. 높은 도약 때 일부 큰 뿔은 상단 HUD 가까이 올라갑니다. 배경·새 아트·3D 리그는 추가하지 않았습니다. 낙석 경로 검사는 근사 모델로 모든 입력 조합의 안전성을 증명하지 않으며, 짧은 검사에서의 FPS는 장시간 성능 보증이 아닙니다.

Unity/D3D12 종료 시 남는 ComputeBuffer 및 비축출 리소스 정리 메시지는 로그에 보존합니다. 플레이 중 Error/Exception/Assert 검사는 별도로 기록합니다. 기존 세대 실행 파일과 원본 플레이어·아트는 보존하고 로컬 커밋만 수행합니다.
